# Box Creator

3D プリント用の「蓋付き箱」の STL を、ブラウザだけで生成する静的 Web アプリです。

- 形状の生成は Ruby で書かれています。mruby を WebAssembly にビルドして Web Worker 上で実行します。
- UI、プレビュー（Three.js）、ダウンロードは JavaScript です。サーバーは使いません。
- 蓋の閉じ方は 2 種類です。はめ込みは、下箱の上部の lip に蓋をかぶせ、rib が溝に落ちてカチッと止まります。ネジ式（円筒の箱のみ）は、lip の雄ネジに蓋の雌ネジをねじ込みます。

## 使い方

`docs/` にビルド済みのファイルがそろっています。ローカルで開くには、静的サーバーで配信します（`file://` では Worker と wasm が動きません）。

```bash
python3 -m http.server 8765 --directory docs
```

http://localhost:8765 を開きます。

GitHub Pages では、リポジトリの設定で公開元を「ブランチ / `docs` フォルダー」にすると、そのまま動きます。他の静的ホスティングでも `docs/` の中身を置くだけです。Three.js だけは CDN（jsDelivr、バージョン固定）から読み込みます。CDN に届かない場合もプレビューが出ないだけで、生成とダウンロードは動きます。

## パラメータ

単位はすべて mm です。

| 項目 | 初期値 | 意味 |
|---|---|---|
| 箱の形状 | 四角 | 四角 / 円筒 |
| 内寸 幅 W、奥行き D | 61.6、49.6 | 四角の箱の内寸（下の「内寸の基準」を参照） |
| 内径 | 51.6 | 円筒の箱の内径 |
| 内寸 高さ H | 96 | 床の上面から蓋の天井までの高さ |
| 蓋の閉じ方 | はめ込み | はめ込み / ネジ式（ネジ式は円筒の箱のみ。四角い蓋は回せないため） |
| 高さの分け方 | 蓋の高さ 33 | 蓋の高さか、下箱の高さのどちらかを指定します。下箱の高さは、外から見える高さ（段の肩まで）です |
| 中身 | 空洞 | 空洞 / 円筒を立てる穴 |
| 円筒の直径、個数、穴の深さ | 16、2、20 | 穴の直径は「円筒の直径 + 遊び」です。深さの上限は「下箱の上端 − 床」です |

### 内寸の基準

箱の大きさは内寸で指定します。外形と全高は内寸から計算し、「寸法の確認」に表示します。

| 中身 | 幅、奥行き、内径が指す場所 | 外形 |
|---|---|---|
| 空洞 | 下箱の中 | 内寸 + (LID_WALL + FIT + BASE_WALL) × 2 |
| 円筒を立てる穴 | 蓋の中（下箱に空洞がないため） | 内寸 + LID_WALL × 2 |
| 空洞（ネジ式） | 下箱の中 | 内寸 + (LID_WALL + ネジ山の深さ + ネジの隙間 + BASE_WALL) × 2 |
| 円筒を立てる穴（ネジ式） | 蓋の中で最も狭いところ（ネジ山の頂点） | 内寸 + (LID_WALL + ネジ山の深さ) × 2 |

全高は「内寸の高さ + FLOOR + LID_TOPWALL」です。穴のタイプでは、円筒は穴の底から立つので、収納できる長さは穴の深さで変わります。この値も「寸法の確認」に表示します。

蓋の高さと下箱の高さは、これまでどおり外から見える高さです。初期値の箱の外形は 70 × 58 × 100 です。

### 詳細設定

| 項目 | 初期値 | 意味 |
|---|---|---|
| R_OUT | 5.0 | 外側の縦の角の丸め半径（四角のみ） |
| LID_WALL | 2.0 | 蓋の側壁の厚み |
| LID_TOPWALL | 2.0 | 蓋の天面の厚み |
| FIT | 0.2（円筒は 0.25） | lip と蓋の内壁の隙間（片側） |
| LIP_H | 8.0 | lip の高さ（段の肩から下箱の上端まで） |
| LIP_CHAMF | 0.8 | lip 上端の外側の面取り |
| MOUTH_CHAMF | 0.6 | 蓋の開口部の内側の面取り |
| R_TOP | 1.5 | 蓋の天面の縁の丸め |
| BASE_WALL | 2.0 | 空洞タイプの下箱の壁の厚み（lip の部分） |
| FLOOR | 空洞 2.0 / 穴あり 3.0 | 下箱の底の厚み |
| HOLE_CLEAR | 1.0 | 円筒の直径に足す遊び |
| HOLE_CHAMF | 1.0 | 穴の入口の面取り |
| MIN_WALL | 3.0 | 穴と穴の間、穴と lip の外面の間の最小の壁厚 |
| BUMP | 0.5（円筒は 0.4） | rib が lip の面から飛び出す量（はまり代は BUMP − FIT） |
| BUMP_R | 1.2 | rib の断面の半径 |
| GROOVE_DEPTH | 0.6 | 溝の深さ |
| GROOVE_R | 1.35 | 溝の断面の半径 |
| rib の長さ | 長辺の 45% / 周方向 15 | 四角は長辺の 2 面に、円筒は 90° ごとに 4 か所付けます。溝は rib より 1 mm 長くなります |
| ネジのピッチ | 3.0 | 1 周で進む距離。ネジ山の深さの 2 倍 + 0.4 以上が必要です |
| ネジ山の深さ | 1.0 | 山の高さ |
| ネジの隙間 | 0.35 | 雄ネジと雌ネジの半径方向の隙間 |
| 円の分割数 | 128 | 1 周あたりの分割数（4 の倍数に切り下げます） |

ネジ式では FIT と rib、溝の項目は使いません。LIP_H を増やすとネジのかかりが増えます（初期値で約 1.9 周）。

### ネジ式の形

- 右ネジの 1 条ネジです。蓋を時計回りに回すと閉まり、蓋のふちが段の肩に当たって止まります。
- ネジ山は 45° の台形なので、下箱も蓋もサポートなしで印刷できます。
- はめ具合テスト用リングにも雌ネジが入るので、印刷した下箱にねじ込んで確かめられます。

### 穴の自動配置

- 四角の箱: 行数と列数を調整して長辺方向に格子状に並べます。空きマスが少ない並びを優先し、同じなら間隔が広いほうを選びます。間隔は等間隔の値を 0.5 mm 単位に丸めます（壁厚が足りなくなる場合は丸めません）。
- 円筒の箱: 1 個なら中央、2 個以上なら円周上に等間隔で並べます。
- 入りきらないときは、個数、円筒の直径、箱の大きさのそれぞれについて、どの値にすれば入るかをエラーに表示します。

### 出力

| ファイル | 向き |
|---|---|
| 下箱 | 底面が z = 0 |
| 蓋 | 天面が z = 0（上下反転。サポートなしで印刷できる向き） |
| はめ具合テスト用リング | 蓋の開口側 10 mm 分。切断面が z = 0 |

## 構成

```
ruby/lib/box_creator/   形状の生成（CRuby と mruby の両方で動きます）
  earcut.rb             穴のある多角形の三角形分割（mapbox/earcut の移植）
  outline.rb            断面ループ、rib と溝の押し出し
  mesh.rb               ループをつないだ側面、水平面、バイナリ STL
  layout.rb             穴の自動配置
  params.rb, model.rb   入力、検証、3 パーツの組み立て
  api.rb                入口（BoxCreator.generate）
wasm/                   mruby のビルド設定と C のグルー（box_generate）
docs/                   公開する Web アプリ（box.js、box.wasm はビルド生成物）
test/                   テスト
scripts/                ツールチェーンの取得、wasm のビルド
```

形状は汎用のブーリアン演算を使わず、z 方向に積み重ねた断面ループを直接つないで作ります。ネジ山も同じ方法で、高さと角度で決まるネジの位相に応じて、各ループの頂点を半径方向に動かして作ります。雌ネジの半径は、どの位相でも雄ネジの半径に隙間を足した値です。ネジ山の端では材料が減る側へ薄れていくので、螺旋に沿って動かしても干渉しません。

earcut の移植には、本家と違う点が 2 つあります。

- 一直線上の頂点を残します。本家はこれを間引きますが、rib のために直線辺へ足した頂点が消えると T 字接合になり、メッシュが閉じなくなるためです。
- 極端に細い三角形は、他に候補がなくなるまで作りません。float32 に丸めたときに裏返るおそれがあるためです。

JavaScript とは次の関数だけでやり取りします。

```c
char *box_generate(const char *params, int part, int *out_len);
```

`params` は `key=value` を改行で並べた文字列です（JSON 用の依存を増やさないため）。`part` は 0 下箱、1 蓋、2 リング、3 寸法情報です。入力エラーは `!ERR` で始まる文字列で返り、Ruby の例外は `out_len` が負の値になります。

## ビルド

mruby（既定で最新のリリース）と emsdk を `vendor/` に取得します。システムには何もインストールしません。mruby は 4.0.0 で確認しています。

```bash
./scripts/setup_toolchain.sh
```

```bash
./scripts/build_wasm.sh
```

`docs/box.js` と `docs/box.wasm` が更新されます。`ruby/` を変更したら、再ビルドが必要です。

## テスト

CRuby で形状を検証します。判定はすべて STL のバイト列に対して行います。

```bash
ruby test/box_test.rb
```

- すべての辺がちょうど 2 枚の三角形で共有され、向きが逆であること
- 自己交差がないこと、体積が正であること、法線が外向きであること
- 外寸、内寸、体積が設定値どおりであること
- 組み立てた位置で、下箱と蓋が断面で干渉しないこと（rib と溝、ネジ山、収納する円筒と蓋を含む）
- ネジが右ネジで、雄ネジと雌ネジが噛み合っていること

wasm の出力が CRuby と一致することを確認します（Node.js が必要です）。

```bash
ruby test/wasm_test.rb
```

ランダムなパラメータで確認します。

```bash
SEED=1 ruby test/fuzz.rb
```

manifold3d を使った独立の確認もできます。`pip install manifold3d numpy` のあとで実行します。組み立てた下箱と蓋のブーリアン積の体積が 0 であることも確かめます。ネジ式では蓋を螺旋に沿って動かし、どの位置でも重ならないこと、逆向きに回すと干渉することも確かめます。

```bash
mkdir -p /tmp/box-stl && ruby test/export_cases.rb /tmp/box-stl && python3 test/manifold_check.py /tmp/box-stl
```
